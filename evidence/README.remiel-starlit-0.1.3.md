## 拍摄版本

- 拍摄时间：2026-11-13，对应 `patches.css` 的 0.1.2 状态。
- 宿主：macOS 桌面端 DSH，皮肤中心按 `$DSH_HOME/skins/remiel-starlit/` 提供样式。
- 主题：亮色 / 暗色各一张，同一会话、同一视口。

## 0.1.3 为什么可以沿用这两张图

0.1.3 的三项改动都不改变**默认亮/暗桌面观感**：

1. `prefers-reduced-transparency: reduce` 内的覆盖——只在系统开启「降低透明度」时
   生效，默认状态不进入该分支。
2. 删除 `[data-dsh-surface='*']` 选择器——该属性当前没有任何插件产出，这些选择器
   本来就匹配不到元素。
3. README 记录跨平台取舍——纯文档。

## 未覆盖的部分（如实说明）

| 状态 | 是否有证据 | 说明 |

权重推算，**不是像素实测**。若维护者要求，可以在有 Windows / 窄屏环境时补图。
