皮肤中心随 dsh-web 家族对齐到统一版本 0.4.20。本区间 `v0.4.19..HEAD` 的功能改动只有一条：修复挂载在子路径反向代理后皮肤中心请求落到源站根路径的问题。

> **兼容性**：没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.19 可直接升上来，也可直接退回，不需要迁移数据。

### 修复

- 皮肤中心浏览器端与首屏样式链接原先全部使用以根路径开头的同源 URL，DSH 挂载在路径前缀下时请求打到源站根而到不了宿主（dsh-web issue #2063）。v2 前缀的两种写法现在集中在纯模块 `src/core/api-prefix.ts`：宿主保留根路径常量，浏览器端据此推导相对文档的基路径；显式注入的 `apiBase` 仍优先。新增 `tests/client-api-base.spec.ts` 钉住该行为。

### 其他改动

- 版本对齐 0.4.19 到 0.4.20，`lib/` 随源码重建；新增一条 Agent Note 与一条过期 PR 关闭决策记录。

Skin Center aligns to the unified family version 0.4.20. The only functional change in `v0.4.19..HEAD` fixes Skin Center requests landing on the origin root when DSH is mounted under a sub-path reverse proxy.

> **Compatibility**: no breaking changes; the `dsh.engines.dsh` floor, peers, engines, package name, export surface, persisted identifiers and wire protocol are untouched. Upgrading from or rolling back to 0.4.19 needs no data migration.

### Fixes

- The browser half and the first-paint style links used root-absolute same-origin URLs, so behind a path-prefix proxy requests resolved against the origin and never reached the host (dsh-web issue #2063). Both forms of the v2 prefix now live in the pure module `src/core/api-prefix.ts`: the host keeps its root-absolute constant and the browser half derives a document-relative base from it; an explicitly injected `apiBase` still wins. `tests/client-api-base.spec.ts` pins the behaviour.

### Other changes

- Version alignment 0.4.19 to 0.4.20 with `lib/` rebuilt; one Agent Note and one stale-PR-close decision record added.
