皮肤中心随 dsh-web 家族对齐到统一版本。本版本新增五个皮肤，把既有皮肤带到宿主 0.1.7 的布局，并重做壁纸目录选择。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-skin-center` 与安装方式不变：npm 包只内置 `blue-fantasy`，其余皮肤仍是市场内容，按需装到 `$DSH_HOME/skins/<id>/`。壁纸选择改为直接使用宿主的目录选择能力，不再扫描 macOS 壁纸库。

### 新功能

- 新增五个皮肤：Claude、桂影月华（mid-autumn）、金碧重彩（shangmei-jinbi）、薇儿丹蒂 · 纯白圣誓（verdandi）、鲸鱼娘 · 未至之境（whale-fantasy，视频背景全息 HUD）
- 皮肤中心：壁纸文件夹选择跟随宿主的目录选择能力

### 修复

- 把 black-gold、blueprint、cafe-roastery、miku、observatory、ice-princess、pixel-anime、whale-maid、blue-fantasy 带到宿主 0.1.7 的布局（代码块、字标列、移动端尺度、会话头与进程行）
- orca-link 的品牌 chrome 坐进桌面外壳的品牌行
- wallpaper-exclusive 的技能中心重新锚定到自己的面板根，不再串到别的面板
- 皮肤中心：去掉 macOS 壁纸扫描，上次挂载未释放时被拒绝的挂载在持有者退出后自动重放

### 其他改动

- README：展示工坊上最受欢迎的三个皮肤
- 契约：登记 dsh-update 的语义属性

The skin center publishes on the family's aligned version. This release adds five skins, brings the existing ones onto the host's 0.1.7 layout, and reworks wallpaper folder selection.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-skin-center` and its install path are unchanged: the npm package still ships only `blue-fantasy`, and every other skin stays market content installed on demand into `$DSH_HOME/skins/<id>/`. Wallpaper selection now uses the host's own directory picker instead of scanning the macOS wallpaper library.

### New Features

- Five new skins: Claude, mid-autumn, Gold and Mineral (shangmei-jinbi), verdandi and whale-fantasy (a video-background holographic HUD)
- Skin center: the wallpaper folder picker follows the host's directory-picker capability

### Bug Fixes

- black-gold, blueprint, cafe-roastery, miku, observatory, ice-princess, pixel-anime, whale-maid and blue-fantasy are brought onto the host's 0.1.7 layout (code blocks, wordmark columns, mobile scale, session header and process rows)
- orca-link seats its brand chrome in the desktop shell's brand row
- wallpaper-exclusive re-anchors the skill center on its own panel root instead of bleeding into another panel
- Skin center: the macOS wallpaper scan is gone, and a mount refused while the previous holder was alive replays after the holder exits

### Other Changes

- README: showcase the three most-liked Workshop skins
- Contracts: register the dsh-update semantic attributes
