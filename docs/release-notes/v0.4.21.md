皮肤中心对齐到统一版本 0.4.21。本区间 `v0.4.20..HEAD` 没有源码改动，只有市场内容的一条皮肤修订：`remiel-starlit` 升到 0.1.2，把面板不透明度按平台差异钉死。

> **兼容性**：没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.20 可直接升上来，也可直接退回，不需要迁移数据。

### 修复

- 官方外壳在 macOS 与 Windows 上给侧栏写了两套表达式：macOS 那条 `color-mix` 把 `remiel-starlit` 的 0.74 alpha 稀释到约 0.299，Windows 保留完整 0.74，且窗口框额外再上一层 `var(--fill)`，中列因此叠到约 0.901，观感明显更不透明、背景几乎看不见；皮肤中心的背景滑杆只推背景遮罩，改不动这两块面板。0.1.2 改为每块面板钉一个字面 rgba 并加 `!important`：侧栏 0.30（浅色）/ 0.29（深色），Windows 专属框层置为 transparent，中、右、底列锁在 bg-base（0.62 / 0.48）。侧栏取的就是 macOS 原本的合成值（0.74 x 0.40），作者视角下 alpha 只差 0.0008。选择器以兼容层打上的稳定钩子 `[data-pane="sidebar"]`、`[data-dsh-frame]` 为主，CSS Modules 类名子串只作兜底。
- 同时补回 0.1.1 市场副本里漏掉的 git 图提交泳道渐变与编辑器选择器 chip。

### 其他改动

- 皮肤的 `noticeUrl` 改指本仓 `skins/remiel-starlit/NOTICE`；证据截图由 jpg 换成同名 png。
- 版本对齐 0.4.20 到 0.4.21，`lib/` 随源码重建。除 `skins/blue-fantasy` 外的皮肤属于市场内容，按本仓提交构建，不在 npm 包内。

Skin Center aligns to the unified family version 0.4.21. Nothing under the package sources changed across `v0.4.20..HEAD`; the only change is one market-content skin revision: `remiel-starlit` moves to 0.1.2 and pins its panel opacity so the two platforms composite the same.

> **Compatibility**: no breaking changes; the `dsh.engines.dsh` floor, peers, engines, package name, export surface, persisted identifiers and wire protocol are untouched. Upgrading from or rolling back to 0.4.20 needs no data migration.

### Fixes

- The official shell paints the sidebar with two different expressions. On macOS a `color-mix` chain dilutes the skin's 0.74 alpha to about 0.299; on Windows the full 0.74 survives and the window frame additionally paints `var(--fill)`, so the centre column composites to about 0.901 and the UI reads far more opaque with the backdrop barely visible. The Skin Center background slider only moves the background scrim, so it could not correct either plate. Version 0.1.2 pins one literal rgba per surface with `!important`: sidebar 0.30 light / 0.29 dark, the Windows-only frame plate set to transparent, and the centre, right and bottom columns held at bg-base (0.62 / 0.48). The sidebar value is the exact macOS composite (0.74 x 0.40), so the author's own appearance moves by 0.0008 alpha. Anchors are the stable hooks stamped by the compat layer, `[data-pane="sidebar"]` and `[data-dsh-frame]`; the CSS Modules class substring is a fallback only.
- Restores the git-graph commit lane ramp and the composer selector chips that were missing from the 0.1.1 market copy.

### Other changes

- The skin's `noticeUrl` now points at this repository's `skins/remiel-starlit/NOTICE`; the evidence screenshots move from jpg to the same names in png.
- Version alignment 0.4.20 to 0.4.21 with `lib/` rebuilt. Every skin except `skins/blue-fantasy` is market content built from this repository and is not inside the npm tarball.
