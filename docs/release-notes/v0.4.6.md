皮肤中心发布 0.4.6，沿用 dsh-web 家族的统一版本号（主仓当前为 0.4.5）。本版本把「由插件提供的皮肤」接进目录，让它作为可选外观参与选中与启动恢复；新增两个皮肤；支持视频资源的 HTTP 分段读取；为市场安装的皮肤加上批量更新与批量卸载；并修掉两个客户端互相覆盖选中状态、以及 macOS 折叠侧栏量不到宽度的问题。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-skin-center` 与安装方式不变：npm 包只内置 `blue-fantasy`，其余皮肤仍是市场内容，按需装到 `$DSH_HOME/skins/<id>/`。

### 新功能

- 插件提供的皮肤成为可选外观：委托皮肤的选中状态由皮肤中心持久化、在启动时恢复，页面交给对应插件绘制。目录在该插件尚未安装时就展示这一行——这一行本身就是安装入口，安装走宿主自己的插件管理器——并且只有插件确实在运行、且它的构建声明了交接口时，才提供试穿与应用
- 批量维护：新增只读的版本查询，把已安装目录与公开市场清单对照；由此提供「全部更新」与「全部卸载」两个按钮。两者都逐个复用已有的单皮肤修复与卸载路由，而不是另开一个写接口，因此每处写入仍走已单独测试过的路径，卡片能报告进度。市场清单读不到或格式不对时失败关闭——报错并不返回任何行，绝不返回一个会被读成「全部都是最新」的空集合。卸载全部会连同当前激活的皮肤一起卸载，然后把界面交回默认外观；内置皮肤（随包发布）始终不动；与单皮肤卸载一样，首次点击只做待确认
- 新皮肤：鲸鱼娘 · 水墨丹青（Whale Girl · Ink Wash，PR #53）——暗色专用、视频背景，一张宣纸被墨淹没后停在一张静帧墨画上；五阶墨色加一点墨绿，边框与骨架是画出来的笔锋与墨点。交付的源片是 HEVC，而 HEVC 在 Chromium 家族（Electron / WebView2）是平台相关的支持（实测 Edge 123 不支持、Chrome 154 支持），发行档因此只改编码格式为 H.264，帧数、帧率、时长、分辨率与硬切回接点一律不动（24.20 MB，SSIM 0.9936；打包 24.70 MB，比商店 25 MiB 的资源上限低 1.44 MiB）。两份 README 与 `skin.json` 都写明角色授权与素材来源
- 新皮肤：零点契约（Midnight Contract，PR #55）——黑金契约界面的亮暗双主题，保留真实会话、模型配置与工具交互

### 修复

- 视频资源支持 HTTP 分段读取：`assets/` 与 `preview/` 的静态响应带 `accept-ranges`，合法的 `Range` 请求回 206 与 `content-range`，带后缀的范围请求也支持，无法满足的范围回 416 而不是整段失败，播放器不再为了开头几秒拉取整个素材（PR #56）
- 只读的一方不再回写选中状态：启动恢复与跟随另一客户端都改走不写盘的路径，同一 `DSH_HOME` 上两个客户端并存时，后启动的一方不再覆盖另一方更新的选择（#54）
- 委托皮肤在目录里改成置顶横条，而不是网格里的方块；横条只写介绍、安装按钮与市场对齐，介绍进字典并跟随界面语言；让出页面不再被说成「没有运行」，横条据实说明并保留切回按钮
- maid-atelier：macOS 桌面端的折叠侧栏是零宽网格轨道，而唯一能反映宽度的 ResizeObserver 挂在侧栏列上、折叠时不触发，右侧补量逻辑又被 `resizeObserver === undefined` 挡住（在任何支持该 API 的浏览器里都不成立，是死代码），导致整幅画框右移一个侧栏宽。现在观测器保持沉默时直接测量
- miku：窗口装饰改由钩子钉住，不再依赖 `patches.css`；并删掉隐藏宿主面包屑的通配规则

<summary>English</summary>

The skin center publishes 0.4.6 on the family's shared version line (the monorepo itself is on 0.4.5). This release brings plugin-backed skins into the catalog as selectable looks that survive boot, adds two skins, serves video assets over HTTP range requests, adds bulk update-all and uninstall-all for market-installed skins, and fixes two clients overwriting each other's selection plus a macOS collapsed-sidebar measurement failure.

> **Important change**: there is nothing to migrate by hand in this release. No persisted identifier, wire field or profile format was renamed. The package name `@linxin666/dsh-client-ui-skin-center` and its install path are unchanged: the npm package still ships only `blue-fantasy`, and every other skin stays market content installed on demand into `$DSH_HOME/skins/<id>/`.

### New Features

- A plugin-backed skin is a selectable look: the skin center persists the delegated selection, restores it on boot and hands the page over to the plugin that paints it. The catalog shows the row even before the plugin is installed - that row is the install entry, and it installs through the host's own plugin manager - and it offers try-on and apply only once the plugin is actually live and its build advertises the handoff
- Bulk maintenance: a read-only version query pairs the installed catalog against the public market manifest, and two buttons drive it. Both reuse the existing per-skin repair and uninstall routes one id at a time rather than adding a second mutating endpoint, so every write still goes through the individually tested path and the card reports progress. An unreachable or malformed manifest fails closed - it answers with an error and no rows, never with an empty outdated set that would read as "everything is current". Uninstall-all covers every market-installed skin including the active one and then returns the GUI to the default look; builtins (shipped inside the package) are never touched; like the per-skin uninstall, its first tap only arms the button
- New skin: Whale Girl · Ink Wash (PR #53) - dark-only on a video background: rice paper that ink floods into, then a still painting; five shades of ink with one point of ink-green, and a frame drawn out of brush strokes and ink dots. The delivered footage is HEVC, and HEVC support in the Chromium family (Electron / WebView2) is platform-dependent (measured: Edge 123 unsupported, Chrome 154 supported), so the shipped asset is a codec-only H.264 transcode with frame count, frame rate, duration, resolution and the hard-cut loop point untouched (24.20 MB, SSIM 0.9936; the packaged zip is 24.70 MB, 1.44 MiB under the 25 MiB store asset cap). Both READMEs and `skin.json` carry the character licence and asset provenance
- New skin: Midnight Contract (PR #55) - a black-and-gold contract interface in light and dark, keeping real conversations, model configuration and tool interaction

### Bug Fixes

- Video assets are served over HTTP range requests: static responses for `assets/` and `preview/` advertise `accept-ranges`, a valid `Range` request answers 206 with `content-range`, suffix ranges are supported, and a range that cannot be satisfied answers 416 instead of failing the whole file - a player no longer pulls an entire asset to show its first seconds (PR #56)
- A reader no longer writes the selection it only read: boot recovery and the follower of another client both take a path that does not persist, so with two clients on one `DSH_HOME` the one that boots last no longer overwrites the other's newer choice (#54)
- The delegated skin is a pinned top bar in the catalog rather than a grid card; the bar carries only the intro, its install button aligns with the market, the intro lives in the dictionary and follows the interface language, and yielding the page is no longer reported as "not running" - the bar states what is happening and keeps the switch-back button
- maid-atelier: on the macOS desktop host a collapsed sidebar is a zero-width grid track, the only live width source was a ResizeObserver on the sidebar column that a collapse never fires, and the direct-measurement fallback was guarded by `resizeObserver === undefined` (never true in any browser shipping the API, so dead code), offsetting the whole frame one sidebar-width to the right. It now measures directly when the observer stays silent
- miku: the injected window chrome is pinned by a hook instead of relying on `patches.css`, and the wildcard that hid the host breadcrumb is gone
