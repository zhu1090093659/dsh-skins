皮肤中心随 `dsh-web` 家族对齐到统一版本 0.4.22。本区间 `v0.4.21..HEAD` 包含一项皮肤中心运行时修复、一项市场皮肤修订（`remiel-starlit` 升至 0.1.3）与 2026-11-24 皮肤收录轮记录。

> **兼容性**：没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.21 可直接升上来，也可直接退回，不需要迁移数据。

### 修复

- `[skin-center]` 在通过动态 `import()` 加载皮肤 `facets.client` 的 `hooks.mjs` 前先基于 `doc.baseURI` 解析成绝对 URL，解决 0.4.20 把 `CLIENT_API_BASE` 改为相对路径后 `hooks.mjs` 在子路径挂载下无法导入的问题（#109）。
- `[remiel-starlit]` 升至 0.1.3：在 `@media (prefers-reduced-transparency: reduce)` 下恢复宿主侧栏填充不透明度（浅色 `0.673`、暗色 `0.522`），移除当前安装下永不命中的 `[data-dsh-surface]` 失效选择器头，并在双语 README 与证据说明中补充跨平台取舍（#110）。

### 其他改动

- 新增 2026-11-24 皮肤收录轮 Agent Note。
- 版本对齐 0.4.21 到 0.4.22，`lib/` 随源码重建。除 `skins/blue-fantasy` 外的皮肤属于市场内容，按本仓提交构建，不在 npm 包内。

Skin Center aligns to the unified family version 0.4.22. Across `v0.4.21..HEAD` the repository carries one runtime fix in Skin Center, one market-content skin revision (`remiel-starlit` 0.1.3), and the 2026-11-24 skin intake round note.

> **Compatibility**: no breaking changes; the `dsh.engines.dsh` floor, peers, engines, package name, export surface, persisted identifiers and wire protocol are untouched. Upgrading from or rolling back to 0.4.21 needs no data migration.

### Fixes

- `[skin-center]` Resolve `hooks.mjs` against `doc.baseURI` to an absolute URL before dynamic `import()`, restoring `facets.client` skin hooks after 0.4.20 switched `CLIENT_API_BASE` to a document-relative path for sub-path mounts (#109).
- `[remiel-starlit]` Move to 0.1.3: restore host sidebar opacity inside `@media (prefers-reduced-transparency: reduce)` (`0.673` light / `0.522` dark), drop unused `[data-dsh-surface]` selector heads, and document the cross-platform transparency trade-off in both READMEs and evidence notes (#110).

### Other changes

- Agent Note for the 2026-11-24 skin intake round added.
- Version alignment 0.4.21 to 0.4.22 with `lib/` rebuilt. Every skin except `skins/blue-fantasy` is market content built from this repository and is not inside the npm tarball.
