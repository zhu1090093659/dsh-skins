# Frutiger Aero

A Frutiger Aero skin for the DSH Web GUI: ice-blue translucent glass panels over an original sky-and-grass wallpaper, with slowly rising glossy bubbles.

## Highlights

- **Original procedural artwork** — the background (`assets/aero-sky.webp`) is fully generated by code (sky gradient, sun, clouds, grass field). No third-party images, no copyright concerns. MIT licensed.
- **Faithful bubble recipe** — the bubble appearance (white shell with an alpha curve, specular highlight at the upper-left, secondary reflection at the lower-right) was measured from the classic Windows bubble screensaver sprite (a 36-direction radial profile, 1% steps) and re-implemented as pure CSS gradients with `transform` compositor animation (no repaints, no `will-change` hacks).
- **Full token remap** — every `--dsw-alias-*` and `--aion-*` token is remapped to the cold ice-blue palette; light and dark variants are both complete.
- **Readability budgeted** — text colors were chosen against the composite glass background; body and secondary text meet WCAG AA.

## Design language

| Role | Light | Dark |
| --- | --- | --- |
| Canvas | `#CDE8FA` | `#081a2e` |
| Glass panels | white at ~22% of the background-opacity scrim | navy at ~20% + scrim |
| Text | `#0B2540` | `#DCEBFA` |
| Accent | `#3FB8E8` | `#5AC8F5` |

Bubbles: 6 per 500px tile, fixed pixel radii (44–92px), single-layer gradients, rising at 25px/s. The animation translates exactly one tile per cycle, and the layer extends one tile beyond the viewport bottom, so the field covers the screen at every instant and loops seamlessly. Circles are kept fully inside their tile so the tile boundary never clips them.

## Frosted glass and performance

Frost is applied to four structural regions through their real CSS-Module class
names (matched with `[class*=]`, since the hash prefix changes between builds):

| Region | Selector | Radius |
| --- | --- | --- |
| Left workspace column | `[class*="sidebarCol"]` | 4px |
| Centre chat column | `[class*="centerCol"]` | 2px |
| Right workspace column | `[class*="rightbarCol"]` | 6px |
| Top titlebar strip | `[class*="_frame"]::before` | 4px |

Measured on an Intel Iris Xe iGPU with the animated bubble field running behind
all of them: GPU 3D engine utilisation stays **below 0.3%** (idle).

The one expensive pattern is a window-level blur: `backdrop-filter: blur(16px)`
on the huge `[data-dsh-part="dialog"]` layer costs roughly **+22%** GPU. That
declaration is deliberately absent.

### Glass edges

The window is treated as a single sheet of glass:

- one highlight on the **top edge of the window** (1px line + ~12px soft decay)
- one on the **leftmost edge** (the sidebar's left side, 15%)
- internal seams carry only a **6% soft light** — enough to hint at the
  partitions without forming a bright line
- **no per-panel borders and no per-panel drop shadows**: a real `border` changes
  layout (the shell's elements are not all `border-box`), and a per-panel edge
  highlight produced a visible white line exactly at the seams
